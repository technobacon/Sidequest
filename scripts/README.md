# Scripts

Store Sidequest Notes scripts here.

## Default writing standard

Every script should follow [`../strategy/SIDEQUEST_SCRIPTWRITING_SKILL.md`](../strategy/SIDEQUEST_SCRIPTWRITING_SKILL.md).

The target is not a polished video essay. It is Matyi talking to one smart friend: calm, researched, conversational, slightly imperfect, occasionally using natural filler words or mild swearing, while the causal structure stays invisible underneath.

Suggested naming:
- `YYYY-MM-DD-short-working-title.md`

Each script should ideally include:
- working title
- thumbnail concept
- one-sentence thesis in plain conversational language
- research/source notes
- hidden causal / viewer-question outline
- final narration
- optional graphics / visual cues

Final narration should be read aloud and revised whenever the written wording is not something Matyi would naturally say.
