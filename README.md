# Sidequest

Sidequest is a low-production YouTube channel about figuring out how to build a good life.

The channel can cover money, work, wellbeing, habits, careers, creativity, YouTube, self-improvement, and other useful parts of modern life. The unifying idea is not a specific topic; it is helping the same viewer make better decisions about how they live.

## Positioning

**Working niche:** young-adult life strategy / life-design commentary.

**Banner line:** `Figuring out life, I guess.`

**Channel voice:** human, analytical, casual, non-guru, useful. The creator is thinking things through with the viewer rather than presenting a perfect life or an expert persona.

## Format

The content is intentionally cheap to produce:

1. Find a strong idea.
2. Research it properly.
3. Write a concise, human script with clear causal progression.
4. Record the narration.
5. Put calm Minecraft gameplay underneath.
6. Add only the graphics that genuinely help: numbers, comparisons, charts, screenshots, short text cards.
7. Upload and iterate quickly.

The gameplay is a visual bed, not the subject of the channel.
